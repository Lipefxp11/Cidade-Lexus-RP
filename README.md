# CIDADE LEXUS RP — Protótipo V13

Godot 4.4.1 • Android • APK exclusivo • interface paisagem • mundo aberto brasileiro fictício.

## Rodando

Abra `project.godot` na Godot 4.4.1. A cena inicial é `res://scenes/main.tscn`.

Depois de enviar os arquivos para o GitHub na raiz do repositório, abra **Actions → Cidade Lexus RP - Android APK**. O workflow exporta um **APK debug** no artefato `CidadeLexus-V13-Android-APK` após uma build bem-sucedida.

Este arquivo está organizado na raiz do ZIP (contém `.github/workflows/android.yml`, `project.godot`, `export_presets.cfg`, `scenes/`, `scripts/`, `assets/`). Não crie pasta interna duplicada!

**Consulte `BUILD_NOTES_V13.md`** para lista de sistemas, controles, teste e limites do protótipo. O jogo é offline, a seleção de servidores online está indisponível até existir backend multiplayer.
